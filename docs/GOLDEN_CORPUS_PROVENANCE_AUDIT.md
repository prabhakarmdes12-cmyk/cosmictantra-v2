## 1. Executive Summary

This audit inspects every expected value in `tests/golden-kundli/fixtures/` (10 Kundli benchmarks + 20 Panchang cases) to determine its origin.

### Strict Provenance Principle:
Any test fixture whose expected values were generated by running the engine under test without comparison against an external, independent, verified source is classified as:
> **`SELF_REFERENTIAL — NOT VALID FOR CORRECTNESS QUALIFICATION`**

Such tests function as **Regression Tests** (ensuring code changes do not alter existing outputs), NOT as proof of astronomical or Jyotish truth.
