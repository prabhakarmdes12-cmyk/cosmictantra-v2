that runs a real OpenType shaper — not because any string was patched.

repository: nothing here has been compared against an external reference. That
is now recorded as structured, fillable evidence rather than as a paragraph of
prose, and D10 is quarantined by a gate that reads it.

## 4. Defects found and fixed this sprint

Each of these was found by a check, not by reading the code.

| # | Defect | Found by | Fix |
|---|---|---|---|
| 1 | **fontkit crashes on `है`.** Noto Devanagari 2.002 has NULL GPOS mark anchors; fontkit dereferences them. Every report with a Hindi sentence failed to render. | bisecting a `KUNDLI_PDF_RENDER_FAILED` | vendored 2.006 into `public/fonts/v3/`; regression test asserts `है` shapes |
| 2 | **Hindi set in a sans face inside Garamond text** — looked like a font substitution because it was one | visual review | Devanagari split by family: Noto Serif Devanagari for serif, Noto Sans Devanagari for sans |
| 3 | **QA rasters silently blank.** `getPixels()` returns a view into WASM memory that detaches when the heap grows; a detached view reports length 0, which every check read as "blank page". Typography pages 3–6 were being skipped. | a `%TypedArray%.slice on a detached ArrayBuffer` throw | copy at the boundary; `inkCoverage` now throws `KUNDLI_QA_EMPTY_RASTER` instead of returning 0 |
| 4 | **Chart house numbers at 6.5 pt** — below the 7 pt legibility floor, on the one label that says which bhava you are reading | `TEXT_BELOW_MINIMUM_SIZE` | house index ≥ 7.1 pt, rashi index ≥ 7.1 pt; hierarchy carried by colour and weight instead of by shrinking |
| 5 | **33 false-positive collisions** on the chart pages, from comparing FONT bboxes with a fixed 1.2 pt tolerance | reviewing the raster against the report | vertical tolerance made proportional to type size (0.45 em) |
| 6 | **Blank-house placeholders in the chart fixture** reserved a text row per empty house, squeezing the abbreviations in every occupied house | `layoutChart` returning 19 planet labels for a 9-graha chart | `occupantsByHouse` now ignores placements without a `planetId`; fixture emits none |
| 7 | **CD-08 silently stopped matching.** The density rule matched the D10 quarantine sentence by a hardcoded regex copy; changing the wording let the long paragraph back onto the consultation page three times. | `densityUnmatched` (now asserted empty) | pattern derived from `D10_PROMOTION.reason`, so the two cannot drift |
| 8 | **Decimal degrees on consultation pages** — combustion separations printed as `13.68°` while every other Pandit-facing degree was DMS | `dms.spec.ts` | `dm()` / `dms()` in `reportModelV2`, `careerSynthesis`, `structuralHighlights` |

## 5. What is still not true

State this plainly, because the sprint's stated success condition is about
trustworthiness, not appearance.

1. **Nothing has been externally validated.** All fifteen cases in
   `GOLDEN_VALIDATION_REGISTER` are `NOT_ATTEMPTED`. The lagna, the planetary
   longitudes, the nakshatra, D9, D10 and the Vimshottari boundaries are
   self-consistent and unverified. This is a data-gathering task, not an
   engineering one.
2. **No Pandit has reviewed the document.** The review pack exists; the review
   does not.
3. **Chromium was not used.** The brief's preferred renderer was unobtainable
   in this environment (§2 of doc 11). pdfkit + fontkit meets the stated
   alternative bar and is tested against it, but it is the second choice and
   the reasons are recorded rather than glossed.
4. **D10 stays quarantined**, and the gate is now wired so that promoting it
   requires evidence rather than a code change.
5. **Shadbala remains unexposed.**
6. **The corpus run has not been done.** One chart (the golden fixture) plus
   three synthetic stress shapes have been rendered. That is not a corpus.
7. **The lagna nakshatra (Magha pada 4) is computed but never printed.** Noted
   in `renderer-v3.spec.ts`; adding it is a content change and out of scope for
   a renderer sprint.

### Recommended next

1. Fill in the external validation register. Start with EV-01 (ayanamsha) and
   EV-02 (lagna): if those two disagree, everything downstream is moot.
2. Get the review pack in front of a practising Pandit.
3. Run the corpus: several hundred charts through pipeline v3, collecting
   structural-audit findings only. No visual review needed — the point is to
   find the layout that breaks.
4. Then, and only then, consider whether `/report` should move off renderer v1.

## 7. Production readiness

**Not production-ready, and the remaining obstacle is no longer typography.**

The success condition was: *a Hindi-reading Pandit opens the PDF, sees
correctly shaped text, understands the chart rapidly, annotates it naturally,
and sees no evidence of the software implementation unless they deliberately
enter the Scholar Appendix.*

Everything in that sentence is now true of the document — verified by machine
for the shaping, the density and the geometry, and by eye for the pages
reproduced in this sprint.

What is not yet true is the sentence that matters more, and which the brief was
careful never to conflate with the first: **the numbers on those correctly
shaped pages have not been checked against anything outside this repository.**
A beautiful document is not a correct one. The register in
`externalValidation.ts` is the shape of the remaining work, and it is empty.
